中文隐私政策

无登翻译（Modern Translator，简称 ModernTrans） 是一款由个人非营利开发者（EU DSA 下的 Non-Trader 非商业主体）维护的完全免费、公益性质开源浏览器扩展，无任何商业收费、内购或广告。本扩展尊重并保护您的隐私，仅用于提供网页划词翻译、网页全文双语对照翻译与语音朗读功能。

1. 我们处理哪些数据

  • 待翻译文本：仅当您主动触发划词翻译、右键菜单、快捷键或网页全文翻译时，扩展才会将您选中的文本或当前网页需要翻译的段落文本发送至您选定的翻译引擎。
  • 配置与密钥：您的语言偏好、界面设置、自定义 OpenAI 兼容接口地址与 API Key 仅存储在本地浏览器的 chrome.storage.local 中，不会上传至与翻译无关的服务器。
  • 临时会话状态：整页自动翻译的标签页/窗口状态保存在本地浏览器的 chrome.storage.session 中，随会话结束自动销毁。
  • 本地缓存：常用短词与短语的翻译结果会缓存在本地 IndexedDB（ndt_translation_cache）以提升响应速度，您可随时在设置页清理缓存。

2. 外部接口传输说明

扩展不会在后台自动采集您的浏览历史。仅在您触发翻译或朗读时，数据会发送至您选择的对应服务商：

  • 微软翻译（Microsoft Translator）：edge.microsoft.com（或按需配置的 api.cognitive.microsofttranslator.com）。
  • 谷歌翻译（Google Translate）：translate.googleapis.com（含 translate_tts 语音朗读）、clients5.google.com 或您填写的镜像地址。
  • 友情赞助商接口（https://api.19781018.xyz）：外部可选的第三方 API 服务；扩展自身无需登录与付费，仅在您主动填入 Key 并启用该服务或查询额度时调用。
  • 自定义 OpenAI 兼容接口：仅发送至您自行填写的 Base URL。

3. 权限说明

  • <all_urls>：用于在您浏览的网页注入划词浮窗与双语译文，并向已配置的翻译接口发起网络请求。
  • storage：保存本地配置（chrome.storage.local）及临时会话自动翻译状态（chrome.storage.session）。
  • contextMenus：提供右键“翻译选中文本 / 翻译当前网页”菜单项。
  • clipboardWrite 与 offscreen：通过离屏文档（offscreen.html）复制译文到剪贴板及播放语音朗读（TTS）。
  • declarativeNetRequestWithHostAccess：仅用于在用户使用谷歌语音朗读（translate.googleapis.com/translate_tts）时移除音频响应跨域限制头，不会读取或修改其他无关网站的流量。

4. 承诺声明与联系方式

  • 不收集任何个人身份信息（PII），不包含第三方广告、统计埋点或跨站追踪脚本，不出售或共享用户数据。

English Privacy Policy

Modern Translator (ModernTrans) is a completely free, non-profit, open-source browser extension maintained by an independent individual developer (Non-Trader status under the EU Digital Services Act), with no paid plans, in-app purchases, or ads. It respects and protects your privacy and is solely dedicated to text selection translation, full-page bilingual translation, and text-to-speech playback.

1. Data Handling

  • Text to Translate: Only when you explicitly initiate a translation does the extension send the selected text or webpage paragraphs to your chosen translation provider.
  • Settings & API Keys: Preferences, custom endpoints, and API keys are stored locally in chrome.storage.local and are never transmitted to unrelated servers.
  • Transient Session State: Per-tab/window auto-translation states are kept locally in chrome.storage.session and cleared automatically when the session ends.
  • Local Cache: Short translation results are cached locally in IndexedDB (ndt_translation_cache) and can be cleared anytime in settings.

2. External Services

No browsing history is collected in the background. Translation or TTS requests are sent strictly to the engine selected by the user:

  • Microsoft Translator: edge.microsoft.com (or api.cognitive.microsofttranslator.com when configured).
  • Google Translate: translate.googleapis.com (including translate_tts audio playback), clients5.google.com, or a user-configured mirror URL.
  • Community Sponsor LLM (https://api.19781018.xyz): An optional external third-party API endpoint; the extension itself requires no login or payment, and only contacts this host when you configure an API key or check quota.
  • Custom OpenAI-compatible APIs: Sent strictly to the Base URL you configure.

3. Permission Disclosures

  • <all_urls>: Required to inject the selection popover and bilingual full-page translations on webpages and send translation requests to built-in or user-configured API endpoints.
  • storage: Persists preferences in chrome.storage.local and transient auto-translate state in chrome.storage.session.
  • contextMenus: Provides right-click actions for translating selected text or full webpages.
  • clipboardWrite & offscreen: Uses an offscreen document (offscreen.html) for clipboard copy and audio/TTS playback.
  • declarativeNetRequestWithHostAccess: Used solely with net_request_rules.json to remove Cross-Origin-Resource-Policy on translate.googleapis.com/translate_tts for audio/TTS playback. Unrelated traffic is never read or modified.

4. Commitments & Contact

  • No collection of personally identifiable information (PII), no third-party ads, analytics SDKs, or behavioral tracking, and no sale or sharing of user data.
